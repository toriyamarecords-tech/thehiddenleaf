# HIDDEN LEAF

An interactive, source-linked cannabis field dictionary exploring everyday language, personal reflection, and scientific evidence.

## Run locally

Open `index.html` in a modern browser. The site is a static page and has no build step or package installation.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
4. GitHub Pages will publish the root `index.html`.

The page loads fonts from Google Fonts and photographs from Unsplash. Those assets need an internet connection; the dictionary and interactions are included in the page itself.

## About the guide

- Three dictionaries: Everyday, Spiritual, and Scientific.
- Search, topic and evidence filters, related terms, and a visit-only reading list.
- A private frequency reflection tool. Its values remain in the page and are not submitted or stored.
- A scroll-based introduction and selectable visual environments.

Spiritual entries describe personal interpretations, not universal facts. Scientific entries distinguish evidence from uncertainty and link to health and research sources. This educational guide does not encourage cannabis use and is not medical advice.

## Typography

Newsreader gives editorial headings and dictionary terms a reflective, field-guide character. Inter keeps paragraphs, navigation, and controls clear and familiar. DM Mono is reserved for compact labels, chapter markers, and evidence metadata.

## Continue building
